# STATUS - Destaque da linha

Extensão do Chrome que destaca a linha da célula selecionada na planilha STATUS (abas CARGAS ATIVAS, DADOS e HISTÓRICO).
Roda só no navegador: não altera a planilha e não envia dados.

- `status-destaque.crx`: extensão empacotada.
- `update.xml`: arquivo de atualização consultado pelo Chrome (instalação forçada pelo Admin Console).
