# Grupo Trajeto - Agenda GTI

Extensão do Chrome do Grupo Trajeto. Quando o Agenda (agenda.trajetologistica.com.br) abre o GTI da Trajeto ou da Coruja para sincronizar o cadastro, a leitura começa sozinha. Não lê nem guarda senha.

- `status-destaque.crx`: extensão empacotada (nome do arquivo mantido por causa do endereço de atualização).
- `update.xml`: arquivo de atualização consultado pelo Chrome (instalação forçada pelo Admin Console).
